# P1040

Source file: `forms-instructions-and-publications/publications/p1040.pdf`

Title: `Publication 1040 - TAX AND EARNED INCOME CREDIT TABLES`

Role in the tax program:

- source for the `2025 Tax Table`, `2025 Tax Computation Worksheet`, and `2025 EIC Table` used by the core `1040` flow
- high-value reference for `Form 1040` line `16` tax computation and earned income credit table lookups
- not a narrative guide; it is a tables booklet that supports numeric lookup paths in the return engine

Front-of-document signals:

- Tax Table
- 2025 Tax Computation Worksheet
- 2025 EIC Table
- TAX AND EARNED INCOME
- CREDIT TABLES

Implementation takeaways:

- when `Form 1040` instructions direct the filer to use the tax table, computation worksheet, or EIC table, this booklet is the local source
- the line `16` engine should preserve the branch between ordinary table lookup and special-worksheet computation
- EIC lookups should stay year-specific because the table values and bands change from year to year
