# I1040GI

Source file: `forms-instructions-and-publications/instructions/i1040gi.pdf`

Title:

- `Instructions for Form 1040 (2025)`
- includes instructions for `1040`, `1040-SR`, and Schedules `1` through `3`

High-value implementation takeaways:

- this is the main line-routing source for `f1040`
- it explicitly states that taxpayers born before `January 2, 1961` may use `1040-SR`
- it is the main source for filing-status logic, dependent section requirements, and the numbered-schedule trigger map
- the numbered schedules should not be treated as optional extras once their triggering facts are present

2025 items surfaced early in the instructions:

- standard deduction amounts:
  - single / MFS: `15,750`
  - MFJ / QSS: `31,500`
  - HOH: `23,625`
- due date: `April 15, 2026`
- Schedule `1-A` is new and holds several 2025 deductions that should not be forced into Schedule A

Line-routing implications:

- the form and schedule set is fact-triggered
- if a taxpayer has adjustments, certain credits, or certain other taxes, one or more numbered schedules become required
- schedule visibility in the UI should follow actual use / dependency, not only manual add actions

Data-model implications:

- filing status should remain one-hot
- dependent facts must preserve enough detail for child-tax-credit vs other-dependent-credit routing
- age-related rules should be computed where the worksheet or instruction naming makes the needed computation obvious
- line `16` tax should be driven by the ordinary tax table / computation worksheet / special worksheet branch, not a single generic formula

Audit cues for current model:

- any field labeled with an explicit date-based fact such as `Age as of 1-1-2026` should be checked for formulaic derivation, not left as a stale default
- schedule-trigger logic should be reviewed whenever new source blocks are added to ensure the needed form or worksheet becomes visible and reviewable
