# P561

Source file: `forms-instructions-and-publications/publications/p561.pdf`

Title: `Publication 561 - Determining the Value of Donated Property`

Role in the tax program:

- valuation companion to `Pub. 526`
- governs fair market value concepts and support for noncash charitable contributions

Core purpose:

- help donors and appraisers determine value of donated noncash property
- explain what information supports the charitable deduction claimed

Important boundary:

- this publication is about valuation and support
- it does not itself determine total deduction limits or all substantiation rules; those belong mainly to `Pub. 526`

Core valuation principle:

- deductible value generally starts with fair market value on contribution date
- FMV = price between willing buyer and willing seller, neither compelled, both informed

Relevant valuation factors listed:

- cost or selling price
- sales of comparable property
- replacement cost
- appraiser opinions
- condition / desirability / scarcity / market demand

Important examples:

- used clothing FMV is typically far below original purchase price
- insured/replacement value is not automatically FMV for donation purposes
- option grant is not contribution until charity exercises option

Current reminder:

- certain partnership / S corporation conservation contributions can be disallowed if they exceed basis-related thresholds

Main forms:

- `Form 8283`
- `Form 8282`

Critical modeling implications:

- noncash donation value should not be guessed from original purchase price alone
- different asset types need different valuation evidence
- date of contribution matters materially

Model-building takeaways:

- for noncash charitable gifts, capture:
  - property type
  - condition
  - acquisition details
  - valuation method
  - appraisal details if any
  - contribution date
  - charity / donee information
- route deduction-limit logic to `Pub. 526`, but keep valuation support fields driven by this publication
