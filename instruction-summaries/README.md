# Instruction Summaries

Concise working notes extracted from the instruction files in `forms-instructions-and-publications/instructions/` and the worksheet source files in `forms-instructions-and-publications/worksheets/`.

Purpose:

- reduce repeated rereading of long IRS instruction PDFs
- make worksheet dependencies visible earlier
- capture line-routing rules, thresholds, and exceptions that are easy to miss when only reading form faces
- support formula audits against source language

Current status:

- initial coverage exists for the core 1040 instruction set and Schedule A
- worksheet tracking exists for the currently modeled `1040` worksheet family
- an audit log exists for source-backed mistakes and known model gaps

Files:

- `INDEX.md`
- `WORKSHEET_INDEX.md`
- `AUDIT_NOTES.md`
- `i1040gi.md`
- `i1040sca.md`
- `i2555.md`
- `federal_info_worksheet.md`

Style goals:

- concise enough to scan quickly
- specific enough to drive model and formula review
- focused on thresholds, worksheet triggers, routing, exceptions, and implementation implications
