# P926

Source file: `forms-instructions-and-publications/publications/p926.pdf`

Title: `Publication 926 - Household Employer's Tax Guide`

Note:

- the file in the repo is the `2026` edition, not a 2025 edition
- still useful as the current household-employment reference in the repo

Role in the tax program:

- governs household employment taxes for taxpayers who employ nannies, housekeepers, caregivers, and similar household workers
- relevant for `Schedule H`, W-2 issuance, withholding choices, and cash-wage thresholds

Current values called out in this repo copy:

- 2026 social security wage base: `184,500`
- social security tax rate: `6.2%` each employer/employee
- Medicare tax rate: `1.45%` each employer/employee
- social security and Medicare taxes apply if household worker cash wages reach `3,000` or more in 2026

Core rule:

- if taxpayer has a household employee, federal employment tax obligations may apply even though this is a personal household setting rather than a business payroll

Important operational rules:

- federal income tax withholding is generally optional unless employee requests it and employer agrees
- `Form W-4` can be used if withholding is agreed to
- `Forms W-2` and `W-3` filing deadlines matter
- payroll outsourcing does not eliminate ultimate employer responsibility

Current extra items in front matter:

- qualified overtime deduction rules affect withholding/pay-statement reporting
- household-employment sick/family leave credits from COVID era are effectively expired for normal current use
- credit-reduction-state FUTA issues can apply
- Medicaid waiver payment guidance may matter in edge cases

Main modeling distinctions:

- employee vs independent contractor classification
- household employee vs business employee
- wages subject to FICA vs not
- optional income-tax withholding vs mandatory payroll-tax obligations

Model-building takeaways:

- support dedicated household-employment intake:
  - worker type
  - cash wages
  - optional withholding election
  - FUTA/state unemployment context
  - year-specific thresholds
- if this project later supports nanny/household payroll reporting, route to `Schedule H` rather than forcing it into ordinary wage logic
